Агент, который помнит твои проекты

Готовая система работы с ИИ-агентом: память между сессиями, автоматические напоминания и один шаг в конце работы.

Собрана из живой настройки, которая используется каждый день. Ставится одной командой.

Открыть репозиторий → Как поставить
Зачем это

Агент не помнит вчерашний день

Каждая новая сессия начинается с нуля. Ты заново объясняешь, что за проект, где лежат файлы и почему нельзя делать вот так. А через неделю агент повторяет ошибку, которую вы уже чинили вместе.

Как обычно

  • Контекст живёт в переписке и умирает вместе с ней
  • Правила приходится повторять каждый раз
  • Одни и те же грабли по кругу
  • В конце работы забыл закоммитить и задеплоить
  • Через месяц непонятно, на чём остановился

С этой системой

  • Контекст живёт в файлах и грузится сам
  • Правило сказано один раз и действует всегда
  • Грабли записаны, агент читает их до работы
  • Конец этапа это одна команда
  • Состояние проекта видно на старте сессии
Что внутри

Шесть частей

Никакой магии: markdown-файлы и несколько bash-скриптов. Всё читается глазами и правится под себя.

🧠

Система памяти

Четыре слоя: глобальные правила, индекс, память проекта, глубокие файлы. Грузится ровно то, что нужно задаче, а не всё подряд.

🪝

Три хука

На старте сессии показывают, над чем шла работа. По ключевым словам подтягивают чек-лист проекта. Перед платной генерацией напоминают про деньги.

⚡

Команда /ss

Конец этапа в один шаг: правила, карта проекта, коммит, деплой на сервер именно этого проекта, обновление памяти.

📁

Структура проекта

Шаблоны CLAUDE.md, AGENTS.md, RULES.md, CURRENT_STATE.md, GUARD.md. Новый проект заводится одной командой вместе с памятью и маршрутами.

🛠

13 скиллов

От транскрибации и описаний для соцсетей до моушен-дизайна и покадрового разбора чужих видео. Ненужные просто удаляются.

📏

Правила работы

Как писать текст, как показывать результат, что проверять перед словом «готово». Стартовый набор, который правится под себя.

Как это работает

День с этой системой

Открываешь папку проекта

Хук сам говорит, над чем шла работа последние дни. Проектный CLAUDE.md подтянулся, состояние прочитано. Пересказывать ничего не надо.

Называешь проект по имени

Хук ловит ключевое слово и подмешивает чек-лист проекта плюс указатель на его память. Чужие проекты при этом не открываются.

Даёшь новое правило

Говоришь «запиши это в память». Появляется файл правила и строка в индексе. Дальше правило действует во всех проектах и во всех сессиях.

Заканчиваешь этап командой /ss

Обновились правила и карта проекта, сделан осмысленный коммит, проект задеплоен на свой сервер, память дописана. Ничего не потерялось.

Установка

Три команды

Установщик спросит имя и рабочую папку, забэкапит текущие настройки, разложит файлы и проверит результат. Повторный запуск безопасен.

# 1. скачать
git clone https://github.com/arturleto/claude-code-starter-kit.git claude-kit

# 2. поставить
cd claude-kit && bash install.sh

# 3. проверить
~/.claude/hooks/doctor.sh

Доктор покажет, на месте ли хуки, не сломались ли маршруты и всё ли есть в индексе памяти. Ноль ошибок значит система живая.

/ss сохранить и задеплоить /transcribe видео в текст /caption описания /reels пайплайн рилса /yt конвейер ролика /potok нарезка reels /video-eyes разбор видео /reels-motion-pro моушен /ui-ux-pro-max дизайн /skill-builder свои скиллы
Требования

Что нужно на компьютере

Базовое ставится одной строкой. Остальное только под те скиллы, которыми будешь пользоваться, список есть в документации кита.

brew install jq ffmpeg yt-dlp git gh python3 node

jq обязателен. Без него хуки молча перестают работать, и система выглядит сломанной без единой ошибки на экране.

Доступ к репозиторию

Репозиторий приватный. Внутри только шаблоны и скрипты, ничего личного, но открыт он по приглашению.

github.com/arturleto/claude-code-starter-kit
Перейти в репозиторий → Написать за доступом

Если открывается страница 404, значит доступ ещё не выдан. Пришли свой ник на GitHub, и приглашение придёт на почту.
